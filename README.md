# Veterinary Management Platform

Trabajo Fin de Máster desarrollado siguiendo un enfoque **Spec-Driven Development (SDD)**: los requisitos y specifications actúan como fuente de verdad del proyecto, guiando de forma trazable el diseño del dominio, la implementación y la verificación del sistema.

## Estado del proyecto

La implementación del backend en Supabase está en curso. Consulta el
[estado de implementación](docs/IMPLEMENTATION_STATUS.md) para conocer el
punto de control actual y el siguiente slice previsto.

## Estructura del repositorio

* [docs/](docs/) — documentación de producto, dominio, arquitectura, convenciones y decisiones arquitectónicas.
* [specs/](specs/) — specifications funcionales, organizadas por dominio.
* [AGENTS.md](AGENTS.md) / [CLAUDE.md](CLAUDE.md) — reglas para agentes de IA que colaboren en el desarrollo.

Consulta [docs/PROJECT.md](docs/PROJECT.md) para la visión completa del producto.
