# Architecture Decision Records

This directory contains Architecture Decision Records (ADRs) for significant
technical decisions made by the project.

ADRs preserve the context, alternatives, decision, and consequences of choices
that affect architecture or long-term development.

ADR identifiers are sequential and must not be reused.

Accepted and current decisions are listed below.
